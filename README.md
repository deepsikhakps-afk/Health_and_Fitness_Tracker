# 🏋️ VITALS – Health & Fitness Tracker

A modern and responsive **Health & Fitness Tracker** built using **HTML, CSS, and JavaScript**. This application helps users monitor their health by calculating BMI, tracking daily water intake, logging workouts and meals, and visualizing weight progress with interactive charts. All user data is stored locally in the browser using **Local Storage**, ensuring privacy and offline accessibility.

---

## 🚀 Features

* 📊 Interactive Health Dashboard
* ⚖️ BMI Calculator
* 🔥 Daily Calorie Requirement Calculator
* 💧 Water Intake Tracker
* 🏋️ Workout Log
* 🍽️ Meal Tracker
* 📈 Weight Progress Chart
* 💾 Local Storage Support (Data persists after page refresh)
* 📱 Fully Responsive Design
* 🎨 Modern UI with Smooth Animations

---

## 🛠️ Technologies Used
